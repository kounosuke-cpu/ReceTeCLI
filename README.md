# Rece-te CLI

## アプリ概要

Rece-teは、レシートに記載された購入情報を登録し、支出を管理するCLI家計簿アプリです。

購入日、店舗名、支払い方法、商品名、カテゴリー、数量、単価を記録できます。

## 主な機能

- レシート情報の登録
- 登録したレシートの一覧表示
- レシートIDによる検索
- レシート情報の更新
- レシート情報の削除
- 商品ごとの小計計算
- 全レシートの合計金額表示
- 数字と日付の入力チェック

## MVP

今回のMVPでは、レシート情報に対するCRUD機能を実装しました。

- Create　レシート登録
- Read　一覧表示、ID検索
- Update　レシート更新
- Delete　レシート削除

## クラス構成

Main  
アプリを起動するクラス

Menu  
メニューを表示し、各処理を呼び出すクラス

InputUtil  
キーボード入力と入力値のチェックを行うクラス

ReceiptService  
レシートの登録、表示、検索、更新、削除を行うクラス

Receipt  
購入日、店舗名、支払い方法、購入商品を保持するクラス

PurchaseItem  
商品名、カテゴリー、数量、単価を保持し、小計を計算するクラス

## 実行方法

1. Eclipseでプロジェクトを開く
2. srcフォルダ内のreceteパッケージを開く
3. Main.javaを右クリックする
4. 実行からJavaアプリケーションを選択する
5. コンソールに表示された番号を入力する

## 現在のデータ保存方法

登録したデータはArrayListを使ってメモリ上に保存しています。

アプリを終了すると登録データは消去されます。
